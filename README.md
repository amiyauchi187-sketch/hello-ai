# hello-ai

タスクを追加・一覧・完了できる、Node.js 製のシンプルなタスク管理 CLI です。
外部パッケージは不要で、Node.js だけで動きます。

## 必要なもの

- Node.js

## 使い方

```sh
# タスクを追加
node todo.js add 牛乳を買う

# 期限付きで追加(--due は -d でも可)
node todo.js add 買い物 --due 2026-10-20

# 既存タスクに期限を設定 / 変更
node todo.js due 1 2026-10-12

# 期限を解除
node todo.js due 1 none

# 優先度付きで追加(--priority は -p でも可。高・中・低)
node todo.js add 報告書を出す --priority 高 --due 2026-10-20

# 既存タスクに優先度を設定 / 変更
node todo.js priority 1 中

# 優先度を解除
node todo.js priority 1 none

# タグ付きで追加(--tag は -t でも可。複数指定できる)
node todo.js add 職務経歴書を書く --tag 転職 --tag 学習

# "#タグ" の形でも指定できる(# はシェルのコメント扱いになるので引用符で囲む)
node todo.js add 英単語を覚える "#学習"

# 既存タスクにタグを付ける
node todo.js tag 1 転職 学習

# タグを外す / all ですべて外す
node todo.js untag 1 学習
node todo.js untag 1 all

# 未完了タスクを優先度順・期限が近い順に一覧
node todo.js list

# タグで絞り込んで一覧(複数指定すると、すべてのタグを持つタスクだけ表示)
node todo.js list --tag 転職
node todo.js list "#転職" "#学習"

# 完了済みも含めて一覧
node todo.js list --all

# タスクを完了にする
node todo.js done 1

# ヘルプを表示
node todo.js help
```

### 表示例

```
[ ] 2. [高] スープを作る (期限: 2026-10-09, 今日まで)
[ ] 6. [高] 報告書を出す #仕事 (期限: 2026-10-20, あと11日)
[ ] 5. [中] 期限なし
[ ] 3. [低] パンを焼く (期限: 2026-10-09, 今日まで)
[ ] 4. 古い件 (期限: 2026-10-01, 8日超過)
[ ] 1. サラダを作る (期限: 2026-10-12, あと3日)
```

- 優先度が高い順(高 → 中 → 低 → 優先度なし)に並びます。
- 優先度が同じタスクは期限が近い順に並び、期限なしのタスクはその中で最後に表示されます。
- 優先度は `高` `中` `低` のほか、`high` `medium` `low` や `h` `m` `l` でも指定できます。
- タグはタスク名の後ろに `#タグ` の形で表示されます。タグに空白は使えません。
- 未完了タスクには「あと◯日」「今日まで」「◯日超過」が付きます。
- 期限日は `YYYY-MM-DD` 形式で指定します。
- タスク名に空白や記号を含む場合は `"..."` で囲んでください。

## データの保存先

タスクは `todo.js` と同じフォルダの `tasks.json` に保存されます(初回追加時に自動作成)。
このファイルは個人データのため `.gitignore` でリポジトリから除外しています。
